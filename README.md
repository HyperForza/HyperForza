## 🚀 Featured Project

### [NexusBridge](https://github.com/HyperForza/NexusBridge)

**A local-first Windows 11 and Android tablet ecosystem.**

NexusBridge explores seamless communication between Windows PCs and Android tablets, with a focus on local connectivity, security and low-latency experiences.

**Currently implemented:**

- 🖥️ Windows 11 host built with **WinUI 3**
- 📱 Native **Android tablet client**
- 🪟 Virtual extended-desktop capture
- 🎥 H.264 video encoding
- 🔐 Fingerprint-pinned HTTPS communication
- 🔑 Persistent secure device pairing
- 📦 Language-neutral **Protocol Buffers** contract
- 🧪 Protocol validation tests

> The current engineering preview includes a working second-monitor pipeline from Windows to Android.

[**→ Explore NexusBridge**](https://github.com/HyperForza/NexusBridge)
